# GEN-IMG-SFT-Phase-1

本仓库包含第一阶段的三个交付内容：

1. **图像描述评测（`caption-evaluation-suite/`）**：提供图像描述生成与评测代码，以及各模型的基线结果。详见 [Caption 评测 README](caption-evaluation-suite/README.md)。
2. **文生图模型评测（`T2I-imgbench/`）**：提供文生图生成、评测输入整理及各 benchmark 官方评分脚本的调用工具。详见 [T2I 评测 README](T2I-imgbench/README.md)。
3. **图文数据清洗（`data_clean_general/`）**：提供可配置的数据质量过滤、结果导出及人工抽检工具。详见 [数据清洗 README](data_clean_general/README.md)。

各模块的环境安装、数据与模型准备、运行方法及结果说明，请参阅对应的 README。
